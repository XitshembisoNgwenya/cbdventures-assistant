# CBD Ventures AI Assistance

**A Smart Student Companion for Pretoria CBD**

CBD Ventures AI Assistance is a student-focused chatbot designed to help students at Richfield Pretoria Campus discover nearby places, find affordable food, explore study spaces and access walking directions.

The application provides a convenient way for students to get useful information about facilities and businesses around campus.

**Campus:** Richfield Pretoria Campus, 291 Helen Joseph Street, Pretoria

**Live Application:** https://cbdventures-assistant.onrender.com/

## Key Features

- **Smart Chatbot:** Answers questions about nearby restaurants, libraries, shops, banks and other student services.
- **Conversation Memory:** Understands follow-up questions about previously discussed places.
- **Budget Recommendations:** Suggests affordable food options based on a student's budget.
- **Business Previews:** Displays photographs, addresses and descriptions of nearby businesses.
- **Map Integration:** Provides walking directions starting from Richfield Pretoria Campus.
- **Mobile-Friendly Design:** Optimised for students using smartphones.

## Running the Application

Install Node.js 20 or newer.

Start the application:

```bash
npm start
```

Open `http://localhost:3000` in your browser.

Run the project tests:

```bash
npm test
```

## Project Scope

The chatbot and Map components form part of the larger CBDventures application.

The **Chat** and **Map** sections are functional. Home, Pay and Profile are reserved for integration with the other components developed by the project team.
